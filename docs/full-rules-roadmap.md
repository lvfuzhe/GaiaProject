# 完整规则迁移路线

`GaiaState` 已在不修改 PUCT、自博弈和训练器的前提下替换 `MiniGaiaState` 成为默认环境。
当前版本标记为 `standard-v12`：共享核心规则和可复现随机初始设置已经可运行，剩余工作主要是补齐官方内容、
把规范化决策拆成显式玩家选择，以及提升大规模自博弈性能。

## 1. 状态模型

当前不可变状态已经包含：

- 公共地图：星球、主建筑、Lantids 共存矿场、各自联邦标记、卫星数量和盖亚塑形者。
- 初始设置：随机种子、星区编号/旋转/坐标、种族座位、计分、科技、联邦与助推板块。
- 玩家板：资源、能量碗、建筑库存、种族、助推板块和通过状态。
- 研究板：六条轨道、科研最高等级钥匙、基础科技和公开能量行动槽。
- 计分状态：轮次计分、两个终局排名指标和当前分数。
- 回合控制：收入、盖亚阶段、行动轮转、过轮顺序和清理。

状态哈希必须包含所有会影响合法动作或未来收益的信息，用于搜索树复用和重复状态缓存。

## 2. 动作系统

当前策略头使用 557 个固定动作，覆盖 40 个地图星球槽位上的建造、盖亚化、四类升级、两类学院、六轨科研、公共能量行动、
科技选择、组建联邦、两项助推特殊行动和过轮选助推。资源支付采用唯一规范方案，联邦使用最少卫星方案，避免
把等价支付和连接方案展开为额外搜索层。

后续若需要忠实复现所有自由行动和玩家选择，应引入结构化动作：

```text
Action {
  kind,
  target,
  payment_plan,
  optional_choice
}
```

动作编码器负责在结构化动作和策略索引之间转换。高分支动作可以使用自回归策略头，联邦
候选通过渐进拓宽逐步加入搜索节点。

## 3. 实施顺序

1. `[x]` 资源、收入上限和完整建筑库存。
2. `[x]` 能量碗、充能、消耗、弃置和自动被动充能。
3. `[x]` 六条研究轨、基础科技选择和公共能量行动。
4. `[x]` 盖亚化、跨维星球、盖亚区和盖亚阶段。
5. `[x]` 联邦强度、规范化最少卫星连接、令牌与科研钥匙。
6. `[x]` 助推选择、轮次计分和两项终局排名。
7. `[~]` 14 个种族的随机分配和起始设置；Terrans、Xenos、Taklons、Geodens 已有部分核心差异。
8. `[ ]` 其余种族能力与全部种族特殊行动。
9. `[~]` 7/10 星区随机拼接、完整初始板块池；官方星区精确坐标与全部板块效果待补齐。
10. `[~]` 高级科技、公共能量行动与学院行动已接入；QIC 自由转换、失落星球与其余自由行动仍待实现。

当前被动充能自动接受，科技和联邦奖励使用确定性选择。这些约束保证 PIMCTS 每一步都是
当前玩家决策，但与实体桌游的完整选择空间不同。

每一步都应添加规则示例测试、随机合法对局测试和状态序列化往返测试。

## 4. 网络升级

当前模型已按人数拆分：2 人局使用 NNUE 特征累加器与反对称价值头；3/4 人局使用
KataGo 风格的全局门控残差塔、策略头和多人价值头。训练、评测、检查点和人机对战均会
验证架构与人数是否匹配。

当前两种网络仍读取统一的结构化扁平观察。进一步扩大规则内容后，可继续拆分三个编码分支：

- 六角地图使用图神经网络或带坐标位置编码的 Transformer。
- 玩家板和研究板使用实体 token 编码。
- 全局轮次、计分和行动玩家信息使用全局 token。

融合后的表示连接自回归策略头和多人价值头。价值头可同时预测排名、最终得分和分差，
通过辅助损失改善前期稀疏反馈。

## 5. 性能门槛

开始 GPU 自博弈前，规则引擎应满足：

- 状态转移和合法动作生成完全确定。
- 随机合法对局能够运行至少十万局而无非法状态。
- 支持批量网络推理，多个 CPU actor 共享 GPU inference server。
- 搜索节点避免深复制大对象，优先使用结构共享或可撤销状态。
- 自博弈、训练和竞技场使用独立随机种子并记录配置。

目前已通过单元测试、随机合法对局和 PUCT 接口测试，但尚未达到十万局属性测试门槛。
当前同步单局推理适合正确性验证；规模化训练仍需 actor/inference-server 批处理层。
