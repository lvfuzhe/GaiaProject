## 已修复差异

- BGA 建筑 `7/8/9` 的含义修正为知识学院、Q.I.C. 学院、行星研究院。
- BGA 联邦板块编号转换为本地规范顺序；`8 VP + 2 能量片` 不再误算为 7 VP。
- `notifyRace6Swap` 现在实际交换 Ambas 的矿场和行星研究院。
- 高级科技会记录被覆盖的基础科技，Q.I.C. 科技行动会记录开销。
- `notifyGainResource` 内的联邦、科技、科研轨和公共行动 VP 全部进入明细账。
- 本地人机对战补齐 7 种普通自由兑换，并按 BGA 口径计算终局可兑换资源。
- 历史回放显示每条 VP 的玩家、原因、通知类型和增减值；明细与局面不一致时显示错误提示。

## 通知语义

| BGA 通知 | 功能 | 本地状态影响 |
| --- | --- | --- |
| `gameStateChange` | 状态机切换 | 更新阶段、当前行动玩家和可选操作 |
| `gameStateMultipleActiveUpdate` | 并行行动玩家更新 | 更新同时需要作出选择的玩家集合 |
| `notifyAction` | 公共或特殊行动 | 标记行动工位或板块行动已使用 |
| `notifyAddRaceDraft` | 加入种族竞选池 | 增加竞选候选种族 |
| `notifyBanRaceDraft` | 禁用竞选种族 | 移除竞选候选种族 |
| `notifyBuild` | 建造 | 更新星球、建筑、资源和建筑供应 |
| `notifyChargePower` | 充能 | 更新三个能量碗、盖亚区和脑石位置 |
| `notifyChooseBoosterTile` | 选择助推板块 | 更新助推板块归属 |
| `notifyChooseRace` | 选择种族 | 确定种族、初始资源、科研和竞拍后 VP |
| `notifyConvert` | 自由兑换 | 应用普通、种族或盖亚区资源兑换 |
| `notifyFormFederation` | 组建联邦 | 标记联邦建筑并放置卫星 |
| `notifyGaiaDone` | 盖亚阶段结束 | 完成盖亚阶段并进入后续阶段 |
| `notifyGaiaformed` | 盖亚化完成 | 将超空间星球翻为盖亚星球 |
| `notifyGainResource` | 资源结算 | 应用资源及内嵌的即时 VP 变化 |
| `notifyGainTech` | 获得科技 | 获得科技、覆盖基础科技、支付 Q.I.C. 并翻灰联邦钥匙 |
| `notifyGeneric` | 规则消息 | 记录竞拍、全局补分等没有专用通知的结果 |
| `notifyIncome` | 回合收入 | 更新当前建筑和科技产生的收入明细 |
| `notifyPass` | 过轮 | 结算过轮 VP、选择下轮助推并更新顺位 |
| `notifyPlaceStartingBldg` | 起始建筑 | 记录蛇形起始放置 |
| `notifyPlayerOrder` | 玩家顺位 | 更新首家与行动顺序 |
| `notifyRace6Swap` | Ambas 建筑交换 | 交换一个矿场和行星研究院 |
| `notifyResearch` | 推进科研 | 更新科研轨、知识开销和联邦钥匙 |
| `notifyRoundEnd` | 大轮结束 | 推进轮次或进入终局 |
| `notifyScore` | 显式计分 | 应用轮次、种族、科技、充能或终局 VP |
| `notifySetOptions` | 玩家选项 | 仅更新自动确认等偏好，不改变规则资源 |
| `notifyStartGaia` | 启动盖亚计划 | 放置盖亚塑形者，结算航程 Q.I.C. 与能量 |
| `notifyTakeFedToken` | 获得联邦板块 | 更新玩家持有板块和公共供应 |
| `notifyUpgrade` | 升级建筑 | 替换建筑并应用信用点、矿石开销 |
| `simpleNode` | 流程标记 | 标记日志节点，包括游戏结束 |
| `updateReflexionTime` | 计时器更新 | 只影响 BGA 思考时间，不改变规则状态 |

程序内的权威映射位于 `gaiazero.bga.BGA_NOTIFICATION_FUNCTIONS`；每次导入都会保存已观察通知和未知通知列表。
