# Gaia Project sector artwork

The sector scans in this directory were obtained from the
[BoardGameHelpers Gaia Project map tile catalogue](https://www.boardgamehelpers.com/GaiaProject/TileCatalogue.aspx).

The original Gaia Project artwork and component designs remain the property of
their respective copyright holders, including Feuerland Spiele and Z-Man Games.
These files are included to reproduce the physical sector appearance in the
local monitoring interface. Review the applicable rights before redistributing
the artwork outside this project.
