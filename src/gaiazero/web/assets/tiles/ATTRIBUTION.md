# Gaia Project board tile artwork

The technology, round-scoring, end-game-scoring, and booster scans in this
directory were obtained from the [BoardGameHelpers Gaia Project setup
catalogue](https://www.boardgamehelpers.com/GaiaProject/LoadGame.aspx).

The original Gaia Project artwork and component designs remain the property of
their respective copyright holders, including Feuerland Spiele and Z-Man
Games. These files are included to reproduce the physical board setup in the
local monitoring interface. Review the applicable rights before redistributing
the artwork outside this project.
