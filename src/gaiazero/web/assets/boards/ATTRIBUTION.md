# Gaia Project research board artwork

The `research-board.png` file is Board Game Arena's full-resolution
`gameBoard.png` for Gaia Project. It was downloaded on 2026-08-13 from BGA game
release `260630-1810` under theme release `260812-1015`:

`https://x.boardgamearena.net/data/themereleases/260812-1015/games/gaiaproject/260630-1810/img/gameBoard.png`

`scripts/build_research_board.py` downloads the file and verifies its SHA-256
digest before replacing the local asset.

The original Gaia Project artwork and component designs remain the property of
their respective copyright holders, including Feuerland Spiele and Z-Man
Games. This file is included to reproduce the physical research board in the
local monitoring interface. Review the applicable rights before redistributing
the artwork outside this project.

The `round-board.png` file is Board Game Arena's `roundBoard.png` from the same
Gaia Project theme release and is used as the official public scoring-board
background in the history replay view.
